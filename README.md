mend applies an edit that an AI model wrote to a tree of text files, in four formats: unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits. It matches lines at three tiers (exact, trailing-whitespace, trimmed), applies every edit or none, and reports exactly what changed.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
